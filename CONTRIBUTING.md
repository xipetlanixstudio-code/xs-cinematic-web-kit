# Contributing / Contribuir

This early-stage toolkit welcomes focused bug reports, accessible motion examples and tests. Open an issue describing the problem before proposing substantial changes. Fork the repository, create a branch and run `npm test` before submitting a pull request. Do not include secrets, client assets or third-party code without compatible licensing.

Este proyecto inicial acepta reportes de errores, ejemplos de animación accesible y pruebas. Abre un issue antes de proponer cambios importantes. Crea una rama en tu fork y ejecuta `npm test` antes de enviar un pull request. No incluyas secretos, recursos de clientes ni código de terceros sin licencia compatible.
