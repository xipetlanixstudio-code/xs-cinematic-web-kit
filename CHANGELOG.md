# Changelog

## 0.3.0 — experimental

- Added continuous static-content rail, controlled in pixels per second.
- Added opt-in playback, native touch scrolling, pause and reduced-motion fallback.
- Added smoothstep transitions and crossfade weights.
- Expanded public demo and regression tests.

## 0.2.0 — experimental

- Added sticky scene progress and numeric keyframe interpolation.
- Added opt-in video scrubbing API.
- Added carousel pause, timed cycling and end wrapping.
- Expanded demo and API documentation.
- Added timeline regression tests and syntax checks.

## 0.1.0 — experimental

- Initial scroll progress, parallax, reveal and native carousel controls.
